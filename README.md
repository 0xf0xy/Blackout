# About

**Blackout** is a raw packet flooding tool designed for network-layer stress testing. It supports both **TCP** and **UDP** flood attacks with randomized IP and port spoofing, enabling high-volume traffic generation for resilience testing and simulation of denial-of-service scenarios.

<br>

# Installation

```bash
git clone https://github.com/0xf0xy/Blackout.git
cd Blackout
pip install .
blackout -h
```
